# Nice Gadgets Store

A modern e-commerce single-page application for browsing and purchasing Apple gadgets — phones, tablets, and accessories. The project features product catalog with filtering and pagination, product detail pages, shopping cart, favorites, and a fully responsive UI with smooth animations.

## Live Preview

🔗 [Nice Gadgets on GitHub Pages](https://yuliiakosenchuk.github.io/nice_gadgets_store/)

> Open in incognito mode to verify full functionality.

## Technologies Used

| Category | Technology |
|---|---|
| UI Library | React 18 + TypeScript |
| Routing | React Router v6 |
| Server State | TanStack Query v5 |
| Client State | Zustand v5 |
| Styling | SCSS Modules |
| Animations | Motion (Framer Motion v12) |
| Carousel / Slider | Embla Carousel |
| Icons | Lucide React |
| i18n | i18next + react-i18next |
| Build Tool | Vite |

## Features

- 📱 **Product Catalog** — browse phones, tablets, and accessories with sorting and pagination
- 🔍 **Product Detail Page** — view full specs, available colors and storage options
- 🛒 **Shopping Cart** — add/remove items, adjust quantity, see total price
- ❤️ **Favorites** — save products for later
- 🌗 **Theme Toggle** — light and dark mode with persistent preference
- 🌐 **Internationalisation** — Ukrainian and English languages (i18next)
- 💀 **Skeleton Loaders** — smooth loading states for all data-fetched sections
- ✨ **Animations** — subtle page transitions and UI interactions via Motion
- 📱 **Fully Responsive** — optimised for mobile, tablet, and desktop

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YuliiaKosenchuk/nice_gadgets_store.git
cd react_phone-catalog
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the project locally

```bash
npm start
```

The app will be available at `http://localhost:3000`

### 4. Build for production

```bash
npm run build
```
